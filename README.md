# Antes de Clicar

Projeto de extensão **Para Transformar o Eu**, do curso de Análise e Desenvolvimento de Sistemas. A oficina trabalha o **ODS 4 · Educação de qualidade** ao ensinar como verificar pedidos recebidos por mensagem antes de clicar, compartilhar dados ou pagar.

O site apresenta a proposta, o guia de verificação, três situações fictícias e um roteiro de entrevista. Abra `index.html` no navegador para usar a versão local. Mantenha `estilos.css`, `oficina.js` e `marca.svg` na mesma pasta.

## Como apresentar

1. Abra o site no celular e use o espelhamento do aparelho, ou abra no navegador já conectado à televisão. Em **O projeto**, apresente o objetivo e as etapas da oficina.
2. Use **Entrevista** para abrir as quatro perguntas. Anote as respostas voluntárias de forma anônima no relato acadêmico ou em papel.
3. Clique em **Modo TV** para apresentar uma situação fictícia por vez. Pergunte ao grupo o que chamou sua atenção e como verificaria o pedido. Depois, abra **Ver resposta comentada**. Use **Próximo** e **Anterior** para navegar e **Esc** para sair.
4. Para comparar a aprendizagem no começo e no fim, use dois casos diferentes dos exemplos comentados no site. Considere se cada pessoa reconhece um sinal de alerta, pausa antes de agir e identifica um canal confiável.
5. Para a exibição do documentário, use **Galeria do encontro** e selecione até três fotos em JPEG, PNG ou WebP com a concordância de quem aparecer. As fotos ficam apenas na aba atual. O envio à DreamShaper é feito no campo de anexos da plataforma.

## GitHub Pages

O site é estático e usa caminhos relativos para funcionar em uma subpasta do GitHub Pages. A origem de publicação é a raiz da branch `main`. A galeria abre imagens na aba atual do navegador. Use a DreamShaper para o envio acadêmico dos registros.

## Verificação

Execute `node --test teste.cjs` dentro desta pasta. Para ensaiar, abra o site diretamente pelo arquivo, ative o Modo TV, revele uma resposta e passe ao próximo caso. Confira as perguntas da entrevista e selecione uma foto de teste na galeria local.
